# 난이도 티어 재분류 & 사진별 티어 스키마 (2026-09-20)

## 배경
- 130종 전부 `difficulty_tier`가 있었지만 tier 1 = 35, tier 2 = 95, tier 3 = 0.
- tier 3이 비어 있어 `selectDecoys`의 "같은 科 유사종 오답" 규칙(최고 난이도)이 한 번도 발동하지 않았다.
- 같은 종이라도 수컷은 쉽고 암컷·유조·겨울깃은 어려운 경우가 많다(원앙, 오리류, 딱새류). 종 하나에 티어 하나로는 표현 불가.

| tier | 종 수 |
|---|---|
| 1 | 35 |
| 2 | 68 |
| 3 | 27 |

## tier 3 선정 기준
1. 실데이터 안에 같은 科 유사종이 1종 이상 있어야 한다(오답 거리감 규칙이 실제로 발동하도록 — 테스트로 강제).
2. 필드 식별에서 실제로 혼동되는 짝·군이어야 한다(색·크기가 뚜렷이 다른 종은 제외).
3. 각 科에 "입문 종"은 tier 2에 남긴다(깝작도요, 노랑턱멧새, 쇠백로, 꼬마물떼새, 알락할미새 등).

## 사진별 티어 스키마
- `SpeciesMedia.difficulty_tier?: 1 | 2 | 3` 추가. 없으면 종 tier를 따른다.
- 의미: 종 `difficulty_tier` = 가장 알아보기 쉬운 형태(대표 사진 = `media[0]`)의 난이도. 더 어려운 형태의 사진에만 더 높은 값을 적는다.
- 검증기(`scripts/validate-data.js`) 규칙: 종 tier 필수(1~3), 사진 tier는 종 tier 이상, `media[0]`에는 금지.
- 서비스 헬퍼: `getEffectiveTier(species, media)`, `getMediaUpToTier(species, maxTier)`, `selectDecoys(..., tier)` 5번째 인자로 실효 tier 주입 가능.
- 예시:
```json
"difficulty_tier": 1,
"media": [
  { "sex": "male",   "plumage": "breeding", ... },
  { "sex": "female", "plumage": "unknown", "difficulty_tier": 3, ... }
]
```

## 아직 안 한 것 (다음 스토리 후보)
- 암컷·유조·겨울깃 사진 수집: 현재 130종 모두 사진 1장, 암컷 사진 0장. 오리과(17종)·딱새류부터.
- 퀴즈 런타임 연결: `QuizQuestion`에 출제 사진(`media` 인덱스)을 담고, `cleanQuality`·`selectDecoys`가 실효 tier를 쓰도록. 지금은 모든 컴포넌트가 `media[0]`만 렌더한다.
- 난이도 진행(잠금 해제): tier 1 → 2 → 3 순서로 출제 범위를 여는 기능은 PRD Phase 2 항목.
- tier 1 승격 후보(친숙·고유 외형이지만 tier 2로 남아 있는 종): 어치, 동박새, 저어새, 두루미, 황조롱이 — 별도 판단 필요.
